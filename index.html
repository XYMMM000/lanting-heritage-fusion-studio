01 / Background

从历史空间到数字共创场域

项目以西交利物浦大学太仓校区的融和馆为文化语境，关注徽派建筑、江南美学、木雕、窗格、屋檐与光影等文化元素。 我们希望通过数字技术降低文化遗产体验的门槛，让用户不只是观看建筑，而是理解、重组并创造属于自己的文化表达。

Heritage 传统建筑与非遗元素
Experience XR 沉浸式探索
Output 3D 打印实体转化

02 / Design Concept

XR-ECO Model：Experience · Co-creation · Output

我们将文化遗产体验设计为一个闭环：用户进入虚拟空间，理解文化元素，进行共创设计，最后通过实体模型完成从数字到物理的转译。

01

Experience

用户进入 XR 场景，观察建筑结构、纹样、材质、灯影与空间氛围。

02

Co-creation

用户通过手势、控制器与 AI 提示重新组合文化组件，形成个性化设计。

03

Output

虚拟作品被导出并转化为 3D 打印模型，让文化体验拥有可触摸的结果。

03 / Core Features

核心功能

Virtual Heritage Experience

在 XR 环境中进入文化遗产空间，感受建筑比例、装饰细节与沉浸式光影。

Modular Element Manipulation

将窗格、屋檐、斗拱、灯具等元素模块化，让用户安全地移动、拆解与重组。

AI-assisted Creation

AI 作为创意催化剂，提供美学解释、历史背景与生成式建议，而不是替代用户决策。

Virtual-to-Physical Translation

将数字创作转化为实体模型，增强情感连接、触觉体验与文化记忆。

04 / Technical Workflow

从文化空间到实体模型

01Cultural Site

采集文化遗产空间与建筑细节。

02Gaussian Splatting

进行高保真三维重建，保留纹理、光影与空间感。

03XR Interaction

构建可探索、可操作、可共创的沉浸式环境。

04AI Co-creation

提供历史解释、造型建议与创意辅助。

053D Printing

把虚拟设计输出为可触摸的实体作品。
